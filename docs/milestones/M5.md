# M5：课程模拟治理业务与事务

实施与验证日期：2026-09-30；交付整理日期：2026-10-01。范围为 PROJECT_PLAN §12、§15.6、§19.7 的 P0 治理流程。状态：本机实现与验收完成。

## 实现范围

从成功风险画像及当前启用、已确认路口建立草稿，冻结画像、评价中心/半径/理由及模拟标记。支持草稿编辑、发布与选执行人、待执行重分配、开始执行、追加记录、提交复核、退回、通过、取消、草稿软删除和只追加历史。LOW/MEDIUM必须说明建立理由，UNKNOWN只能建立FIELD_SURVEY调查草稿，不能发布；允许取消调查草稿。

所有治理接口限ADMIN/MANAGER。MANAGER可查看未删除任务；软删除详情/历史及旧请求重放仅创建者或当前ADMIN可见。创建者/ADMIN管理草稿、发布、重分配、取消与复核；执行动作只属于当前执行人，复核禁止执行人自审，ADMIN也不能例外。状态和权限矩阵见[ADR 0007](../decisions/0007-m5-governance.md)、[状态图](../diagrams/governance-state.md)，字段见[API契约](../api_contract.md)。

0007不增表或列。两个SECURITY DEFINER函数固定search_path并限定关系名，只向app授予EXECUTE；app/worker不能直接写工单/历史或使用相关序列。先取得M1共用账户事务锁，再锁任务并校验当前角色/身份/状态/版本。变更、version+1和history.sequence_no在同一事务，历史失败全部回滚。request-v1绑定操作者、动作、目标、expected_version与规范化内容；同UUID同内容重放不重复写，返回当前授权投影，同UUID异内容或旧版本409。

前端从风险画像行进入建立草稿，展示课程模拟标记、执行待办、状态筛选/分页、当前允许动作、冻结范围与时间线。失败后主动重新加载详情，不自动覆盖其他人的修改；切换账户卸载上一身份的数据。VIEWER隐藏整块治理功能且后端拒绝访问。
