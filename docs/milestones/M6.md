## 实现范围

统计口径（[ADR 0008](../decisions/0008-m6-statistics-export.md)）：所有事故统计先构造一事故一行筛选集合（`statistics.collision_scope`：日期左闭右开、LEFT JOIN 行政区字典、 casualty_stat 一对一；车型/原因用相关 EXISTS 只负责选出事故），再统计选中事故内的全部车辆/人员明细。伤亡只取 `casualty_stat`：`SUM` 为已知值合计、全未知返回 NULL、缺失用 `COUNT FILTER` 单列；原因按 `(collision_id, factor_id)` 去重且无原因事故单列；车型双计数（记录数/事故数）并保留未知组；人员按原始 `person_type×person_injury` 细分；正式归属沿用 M3/M4 定义，覆盖率分母 0 为 NULL。`data_api.collisions` 的筛选委托同一实现，列表/统计/导出一套含义。

月度趋势空月份**不补零**：批次 manifest 的声明范围不构成逐日完整证据，空月份返回 NULL 并标注 `WITH_DATA / NO_RECORDS_COVERAGE_UNCONFIRMED / OUTSIDE_DECLARED_RANGES`；小时分布缺失时间单列，不并入 0 点。

新增接口（前缀 `/api/v1`，均运行在 REPEATABLE READ READ ONLY 快照中，`meta.data_revision` 与聚合同快照）：`/statistics/overview|boroughs|trends|factors|vehicle-types|persons|governance` 与 `/exports/collisions.csv|statistics.csv`。权限：基础统计与事故 CSV 对启用 ADMIN/MANAGER/VIEWER；人员细分、治理统计与统计报表 CSV（含人员节）限 ADMIN/MANAGER，VIEWER 后端 403。治理统计独立筛选（状态/执行人/创建日期 UTC 左闭右开）、排除软删除、未分配单列、总数不连接历史重复累计、"已完成"依据状态。

CSV：事故列表与 `/collisions` 同筛选、`(crash_date, collision_id)` 升序、数据行上限 5,000（取 5,001 行判定），超限 400 `EXPORT_ROW_LIMIT` 拒绝；统一报表 CSV 单快照一次生成七节；UTF-8 BOM+CRLF、`#` 说明行（生成时间/revision/排他区间/筛选/口径/缺失与重叠说明，不计入数据行）、NULL 为空字段、文本列公式起始字符（`= + - @`，含前导空白/控制字符绕过）前置单引号防护，数值与日期列不做整列文本化。

前端：`StatisticsPanel.vue` + `api/m6.ts`（auth.ts 增加返回 meta 的 `apiWithMeta` 与 `authHeaders`，行为兼容）。筛选（结束日含当天→提交次日排他上界）、请求序号防竞态、失败清空旧结果、revision 不一致提示；ECharts 绘制行政区/月度（空月断点）/小时（未知组）/原因 Top10（配完整表格），车型/人员/治理用表格；图表 resize、afterprint 恢复与卸载 dispose；打印样式只保留统计面板并保留口径/缺失/重叠/模拟标记，表格作为可读打印内容；无服务端 PDF。

## 真实失败与修复（保留过程）

1. **GROUP BY 绑定参数不匹配**：`date_trunc('month', …)`/`extract('hour', …)` 在 SELECT 与 GROUP BY 生成两个不同绑定参数，PostgreSQL 无法表达式匹配（GroupingError）。改为 `GROUP BY 1` 序号引用；开发库冒烟先红后绿。
2. **测试夹具触发数据库守卫**：import_batch 直接插 SUCCEEDED 被 `vz_import_guard` 拒绝（必须从 UPLOADED 状态机推进）；OPEN 工单无执行人被 `vz_task_basis_guard` 拒绝。夹具改为按状态机推进、OPEN 任务指定启用管理人员，未放宽任何产品约束。
3. **SQLAlchemy 2.0 API**：`nullsfirst()` 已更名 `nulls_first()`；ORM 实体子查询列引用改为条件列表聚合。
4. **验收脚本缺陷（三轮修正，产品代码不变）**：`find` 返回 h3 后未取 `.print-block` 导致人员/治理检查读取失败；行政区种子为字母序（borough 1=BRONX）导致断言错位；故障注入与瓦片拦截的 `net::ERR_FAILED` 曾被计入 JS 控制台错误，改为预期资源错误单独计数。
5. **打印后图表溢出（真实产品缺陷）**：`page.pdf` 触发 beforeprint 将图表 resize 到打印宽度，返回屏幕后无恢复，页面出现173px横向溢出。组件增加 `afterprint → resizeCharts`，验收补打印后恢复断言，最终33/33通过。
