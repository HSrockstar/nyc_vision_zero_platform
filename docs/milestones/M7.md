## 备份与恢复方法

备份使用同一个 `REPEATABLE READ READ ONLY` 导出快照记录数据摘要，并将快照交给 `pg_dump -Fc`。备份前拒绝正在运行的导入/风险任务，备份后检查序列未变；维护窗口应暂停写入。自定义dump、迁移与锁文件、已登记CSV和成功风险快照保留于ACL收紧的 `.m7-work/backups/<新名称>/`。开发库本轮dump为84,944,662字节；包含4个批次的12个CSV及1个风险快照。未登记的下载源文件不在这13个文件范围内。

单库备份不包含集群角色和外部秘密。恢复重新生成目标专用app/migrator/worker角色与配置，以当前且哈希匹配的迁移创建结构；然后只向这个新库恢复数据。`alembic_version`由迁移创建，`spatial_ref_sys`由扩展创建；schema、扩展版本、视图、函数、约束、索引和触发器定义都与源快照比对。数据恢复使用超级用户、单事务和 `--disable-triggers`，结束后检查没有禁用触发器，并逐个外键扫描孤儿。应用角色实际越权写入、worker读取密码列必须得到权限拒绝；app/worker readiness必须成功。

目标只接受不存在的 `vision_zero_m1_test_<12位小写十六进制>`。已有库、角色、配置、恢复目录或外部数据目录均拒绝复用。失败目标保留用于排查；工具没有删库、覆盖开发库或自动清理失败证据入口。备份清单最后写入；缺清单或文件/迁移摘要不一致时不建目标库。配置和凭据不进入公开证据。

仓库根目录执行以下命令（新库名可用 `[guid]::NewGuid().ToString('N').Substring(0,12)` 生成）：

```powershell
$target = 'vision_zero_m1_test_' + [guid]::NewGuid().ToString('N').Substring(0,12)
Push-Location backend
try {
  ..\.venv\Scripts\python.exe -X utf8 -m app.cli backup-database --output .m7-work/backups/manual-20261003
  if ($LASTEXITCODE -ne 0) { throw '备份失败，保留现场' }
  ..\.venv\Scripts\python.exe -X utf8 -m app.cli restore-database --backup .m7-work/backups/manual-20261003 --database $target
  if ($LASTEXITCODE -ne 0) { throw '恢复失败，保留现场' }
} finally { Pop-Location }
```

维护工具依赖本仓库环境、Docker身份及锁定镜像。当前验证是同机新库恢复；跨主机首次安装、全新操作系统与浏览器整链仍属于M8交付核验。官方参数依据：[pg_dump](https://www.postgresql.org/docs/17/app-pgdump.html)、[pg_restore](https://www.postgresql.org/docs/17/app-pgrestore.html)。

## 失败记录与修正

1. 首轮序列运行校验把官方来源键和固定字典代码的未使用SERIAL默认值也当成内部自增ID，产生失败。检查已改为只探测模型 `IDENTITY` 内部键，探测后显式恢复序列值；[失败](../evidence/M7/failures/runtime-sequence-01.json)和[复验](../evidence/M7/runtime-sequence-final.json)均保留，未重置源库序列。
2. 扩充全部 `SECURITY DEFINER` owner核验时，带参数SQL的 `LIKE 'vz_%'` 被psycopg解析为非法占位符，见[真实错误](../evidence/M7/failures/restore-permission-01.log)。改为前缀比较后，在全新a820目标完成整个恢复；a720失败目标保留，没有补写成功记录冒充首次恢复成功。
3. 新边界测试首轮遗漏导入 `clients` fixture，2 passed/3 errors；[原日志](../evidence/M7/failures/pytest-edges-01.log)保留。补齐fixture后5项全部通过，没有修改产品业务逻辑来迎合测试。

本轮权限核查依据实库拒绝路径与现有后端权限回归，不等于互联网部署渗透测试。T10日期控件、T29地图服务离线降级以及重构后的其他页面均未在本会话验收；因此不把M7整阶段或M8最终交付标为完成。
