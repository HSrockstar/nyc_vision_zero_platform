# ADR 0004：M2真实数据导入与查询

状态：已实施；2026-09-29。范围为三类CSV暂存、校验、发布及事故页面，地图、路口归属、风险与工单留M3—M5。

复用M1的23表和锁定运行环境，新增0003发布幂等字段/诊断去重及运行权限，0004限制app/worker状态边。同步FastAPI处理授权与文件登记，独立worker轮询数据库，不新增队列服务。清洗`nyc-clean-v1`、CSV表头`nyc-csv-v1`均显式版本化，原始CSV、payload、未映射字段和修订指针保留。

状态为UPLOADED→VALIDATING→READY→PUBLISHING→SUCCEEDED。错误或过期作业FAILED；管理员重试只回UPLOADED，不自动发布。租约令牌与数据库实际时钟隔离旧worker；发布是一个事务并重新核对管理员。校验允许行级隔离和非阻断警告，来源键内容冲突、关键表头缺失等阻断整批。人工处理问题只追加审计及处理字段，不把错误原始行变成有效行。

下载首先固定2025年1月前500起稳定排序事故，子表按父ID取完整明细；通过后扩大到三源各自crash_date在2025年内的CSV。后者按实际父子质量记录隔离与覆盖，不能称三源日期永远一致或所有事故都有明细。来源为官方固定域名及Dataset ID；CSV按稳定来源键分页合并，保留CSV字段值、检查点、前后计数、唯一键及SHA-256。年度范围不代表全历史。

查询使用带签名且绑定条件/revision的日期+事故ID游标。联合车型/原因过滤用EXISTS，单独分页人员/车辆，伤亡使用Crashes的casualty_stat，防止一对多放大。VIEWER从后端排除年龄/性别/来源代码；MANAGER导入只读摘要，ADMIN可查问题及受保护raw。前端共享内存登录状态，401/退出清除所有业务面板。

回退：本机开发库不执行业务downgrade；随机验证库验证base回退重升。发布失败靠事务回滚，不删除原始输入。源码回到既有M1提交不等于数据库降级；前向迁移和已保留raw用于修复及追溯。实际验收见[M2记录](../milestones/M2.md)。
